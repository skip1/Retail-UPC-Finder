# Privacy Policy — UPC Finder for Resellers

**Last updated: August 23, 2026**

## Summary

This extension does not collect, store, transmit, or sell any personal
data. It reads publicly visible product information on supported retailer
pages and displays it to you, along with optional links to check that
product's UPC on other sites. Some of those links are affiliate links,
described below.

## What the extension does

- On supported retailer product pages, it reads publicly available product
  data already present on the page (specifically, the UPC embedded in the
  page's own data) and displays it to you.
- On supported retailer search/listing pages, it requests the individual
  product pages for items shown in your results — using your own existing
  browser session, exactly as if you had clicked into each product
  yourself — in order to find and display each product's UPC.
- It lets you click the displayed UPC to copy it to your clipboard.
- It generates links to search that UPC on Google, Amazon, and eBay.
  Clicking any of these links is your action; the extension does not
  automatically navigate you anywhere or submit anything on your behalf.

## Supported sites

Walmart, Target, Best Buy, Costco, Home Depot, and Lowe's. The extension
only requests permission for, and only runs on, these domains.

## What data the extension collects

None. The extension does not:

- Collect or transmit any personal information, browsing history, or
  account data
- Use analytics, tracking pixels, or third-party scripts
- Send any data to any server operated by the developer
- Store any data outside your local browser session (a small in-memory
  cache of previously found UPCs is kept only for the current page
  session to avoid redundant requests, and is cleared when the page is
  closed or reloaded)

## Affiliate links and monetization

This extension is free to use, with no account or subscription required.
Some of the links it generates are affiliate links:

- **eBay** — the eBay link includes an eBay Partner Network affiliate
  tracking ID. If you click this link and make a purchase on eBay, the
  developer may earn a commission. This does not affect the price you
  pay.
- **Amazon** — the Amazon link is a plain search link and currently
  carries no affiliate tag. The developer does not earn a commission from
  Amazon clicks at this time.
- **Google** — the Google link is a plain web search and is never an
  affiliate link.

Clicking a link is entirely your choice. The extension does not
automatically open, redirect to, or pre-fill any purchase on your behalf.

## Network requests

The only network requests the extension makes are to the retailer domain
you are already browsing (e.g., fetching a product page to read its UPC).
These requests use your existing browser session the same way normal
navigation on that site would. The extension does not send data to, or
receive data from, any server controlled by the developer.

## Permissions

The extension requests host permission only for the supported retailer
domains listed above, which is required to read product page content and
to make the background requests described above. It requests no other
browser permissions (no access to browsing history, bookmarks, cookies on
other sites, downloads, etc.), other than clipboard write access, used
solely to let you copy a displayed UPC when you click it.
