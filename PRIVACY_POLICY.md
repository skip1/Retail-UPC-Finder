# Privacy Policy — UPC Finder for Online Shopping

**Last updated: July 31, 2026**

## Summary

This extension does not collect, store, transmit, or sell any user data.
Everything it does happens locally in your browser, on the pages you're
already viewing.

## What the extension does

- On supported retailer product pages, it reads publicly available product
  data already present on the page (specifically, the UPC embedded in the
  page's own data) and displays it to you.
- On supported retailer search/listing pages, it requests the product pages
  for items shown in your results — using your own existing browser
  session, exactly as if you had clicked into each product yourself — in
  order to find and display each product's UPC.
- It generates a link to search that UPC on another retailer's site
  (currently amazon.com/s?k=). Clicking this link is your action; the
  extension does not automatically navigate you anywhere or submit
  anything on your behalf.

## What data the extension collects

None. The extension does not:

- Collect or transmit any personal information, browsing history, or
  account data
- Use analytics, tracking pixels, or third-party scripts
- Send any data to any server operated by the developer
- Store any data outside your local browser session (a small in-memory
  cache of UPCs is kept only for the current page session to avoid
  redundant requests, and is cleared when the page is closed or reloaded)

## Network requests

The only network requests the extension makes are to the retailer domain
you are already browsing (e.g., fetching a product page to read its UPC).
These requests use your existing logged-in session the same way normal
navigation on that site would. The extension does not send data to, or
receive data from, any server controlled by the developer.

## Permissions

The extension requests host permission for the supported retailer's
domain only, which is required to read product page content and to make
the background requests described above. It requests no other browser
permissions (no access to browsing history, bookmarks, cookies on other
sites, downloads, etc.).
